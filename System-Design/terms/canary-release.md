# Canary Release

> [!tldr]
> Ship the new version to a small group of users first, then widen it if nothing breaks.

---

## Where the name comes from

Caged canaries were carried into coal mines. The bird reacted to bad air before the miners did.

---

## The real example

Firefox ships nightly and beta builds. A small, willing group runs the new code long before everyone else gets it.

---

> [!tip] The point is blast radius
> A broken release hits one percent of users instead of all of them, and you find out from real traffic rather than from your test suite.
