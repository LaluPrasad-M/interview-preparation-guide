# QPS (Queries Per Second)

> [!tldr]
> The number of requests a system handles each second, the base unit every capacity estimate is built from.

Interviewers use it to force a number onto an otherwise vague design: given daily active users and an assumed requests per user, peak QPS usually comes out several times higher than the average, and that peak is what has to be provisioned for, not the average.

**Shows up in:** [[capacity-estimation]], [[appointment-scheduler]], [[geospatial-discovery]].
