# Dictionary Candidates from React Notes

Terms encountered in the React notes that might warrant dictionary entries:

| Term | One-sentence meaning | Note |
| --- | --- | --- |
| Debouncing | Delays execution until activity stops, useful for search inputs and API calls. | react-fundamentals.md |
| Throttling | Caps execution to happen at most once every X milliseconds, useful for scroll handlers. | react-fundamentals.md |
| Memoization | Caching a value or function reference to avoid recalculating on every render. | react-fundamentals.md |
| Controlled component | A component whose form state is managed by React state rather than the DOM. | react-fundamentals.md (mentioned in table, not heavily defined) |
| Referential equality | React's method of checking if state changed by comparing memory references. | react-fundamentals.md |

**Notes:**
- Most React-specific terms (reconciliation, virtual DOM, functional updates, dependency array, custom hooks) are well-defined in their own sections and do not need separate dictionary entries.
- Debouncing and throttling are general patterns used beyond React and might deserve dictionary entries.
- The theory questions section explains each concept thoroughly in context.
