# Canary Release

> [!tldr]
> Ship the new version to a small group of users first, then widen it if nothing breaks.

The name comes from caged canaries carried into coal mines: the bird reacted to bad air before the miners did. Firefox does a version of this with its nightly and beta builds, where a small, willing group runs the new code long before everyone else gets it.

> [!tip] The point is blast radius
> A broken release hits one percent of users instead of all of them, and you find out from real traffic rather than from your test suite.
